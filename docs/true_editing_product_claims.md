# True Editing Product Claims

Allowed claim:

Wellfriend supports source-linked true editing across the validated supported
paths, with provenance, transactions, canonical writing, reopen validation,
undo, and binding exposure.

Required limits:

- Unsupported or ambiguous edits return typed refusals.
- Low-confidence semantic or OCR decisions require review.
- Dynamic XFA conversion is not claimed as universal.
- External-tool parity is claimed only for tools that actually ran.

Evidence is in `target/release_validation-enterprise-validation/product-claim-matrix.json`.
