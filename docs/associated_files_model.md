# Associated files model

The Prompt 18 model records a stable id, file-spec and stream references, owner type/reference, AFRelationship, filename variants, description, MIME, size, SHA-256, dates, encryption/decode state, internal/external state, duplicate group, provenance, security class, and sanitizer disposition.

Inventory covers EmbeddedFiles name trees, annotation attachments, owner `AF` arrays, catalog/page/structure/XObject owners, orphan file specs, external/platform specs, and Collection presence. Source, Data, Alternative, Supplement, EncryptedPayload, FormData, Schema, Unspecified, and custom relationships remain distinct. No PDF/A certification is inferred.
