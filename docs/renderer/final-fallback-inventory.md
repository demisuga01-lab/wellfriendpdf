# Final renderer fallback inventory

**Snapshot:** `E:\wellpdfsdk` after the interrupted renderer continuation was repaired for parsing, unsafe-SIMD boundary compilation, scalar-equivalence fallback behavior, scanline coverage, and warnings-as-errors cleanliness.
**Method:** source inspection only. This is not corpus or performance evidence. A “fallback” here means an active branch that changes execution strategy, declines native retained replay, substitutes resources, or loses vector/exact semantic information. It is not a raw search count for the word `fallback`.

**2026-09-07 source-closure note:** full progressive `RenderContract` revision is now active across the core, server, and language-binding source surfaces. Revision rebuilds the tile/output contract and marks old publications obsolete; it does not render fallback pixels. Unsupported retained content is described as outside native retained-plan support rather than as unfinished coverage, and remains a typed refusal with no immediate-render delegation.

**2026-08-28 progressive retained-tile refusal note:** progressive unsupported retained display-list tile replay now records the `unsupported_display_list_retained_tile_refusal` structured event in production report fields before the job enters `Failed`. The output remains typed refusal, not fallback pixels, and the event carries the fallback-inventory policy details for the refused tile.

**2026-08-28 progressive contract-exactness note:** progressive retained-tile refusal events now derive Standard versus high-quality availability from the active `ExactnessPolicy` in the canonical render contract, not from the legacy `RenderMode` string accepted by older start APIs. A `compat` token with a `HighQualityExact` contract therefore reports high-quality refusal policy without publishing fallback pixels or delegating to immediate replay.

**2026-08-28 PostScript exact shading-domain note:** FB-11/FB-12 vector-output policy is narrower for PostScript nonlinear shadings with non-unit shading dictionary domains. Axial/radial vector-shading records carry `/Domain`, and PostScript exact Type 2/Type 3 sidecars emit `/Domain [...]` for finite non-unit domains. SVG still refuses nonlinear function output rather than approximating it.

## Closure policy

- No fallback is treated as proof that a feature is universally implemented.
- Exact/canonical immediate rendering is not labelled approximate merely because it is a different execution strategy; it remains a blocker for the native-retained requirement.
