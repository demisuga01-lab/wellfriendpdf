# Optimization dossier coverage

Coverage is tracked in `evidence/runtime-optimization/dossier-coverage.json`.

Classifications:

- `implemented_existing_verified`
- `implemented_in_this_task`
- `integrated_optional_backend`
- `implemented_provider_interface`
- `benchmarked_and_rejected`
- `superseded_by_stronger_equivalent`
- `research_only_scaffold`
- `unavailable_external_dependency`
- `incompatible_license_rejected`
- `not_applicable_with_evidence`

The public API exposes only `standard` and `research`. Dossier profile terms are treated as internal strategy inputs, not public modes.
