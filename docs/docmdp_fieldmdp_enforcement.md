# DocMDP and FieldMDP enforcement

Schema: `pades_ltv.tsa-dss-ltv-mdp-signature-edits.v1`

DocMDP and FieldMDP structural policy feeds edit planning. Unknown or forbidden changes deny by
default; viewer-specific UI acceptance is not treated as conformance.

Incremental Signing Standards certification signing writes the catalog `/Perms` `/DocMDP` reference and then
reopens the signed document. The existing permission engine must recognise the created policy.
Approval and certification signatures remain append-only; post-sign edit classification reports
permitted form-fill versus prohibited field, annotation, or page-content changes with evidence.
