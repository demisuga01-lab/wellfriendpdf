# Research mode

Research mode is Standard plus optional experimental or accelerated infrastructure:

- GPU and hybrid rendering contracts;
- advanced self-hosted models;
- hosted OCR/VLM providers;
- cloud document-intelligence providers;
- model ensembles and evidence fusion;
- distributed workers;
- learned cost selection;
- hardware autotuning;
- translation-validated display-list optimization;
- experimental solvers and instrumentation.

Research mode must still run without a GPU, LLM, or cloud provider. In that case the complete Standard engine remains active and optional capabilities are reported inactive.

Research claims are not production guarantees unless measured on the target workload. Operator configuration must include capacity planning, isolation, monitoring, data residency, provider budgets, and model-governance controls.
