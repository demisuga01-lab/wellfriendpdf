# Semantic Binding Exposure

Prompt 15 uses `SemanticBindingReport` as the canonical semantic payload. Rust
owns the typed model; public language bindings consume stable JSON generated by
`wellfriendpdf_engine::sdk`. This avoids fragile C object graphs and prevents each
binding from defining a competing semantic schema.

## Canonical Report

Schema: `prompt15.semantic_binding.v1`.

The report includes:

- summary counts for pages, blocks, paragraphs, lines, spans, characters,
  structure nodes, MCIDs, repairs, conflicts, tables, cells, figures, captions,
  CJK tokens, chunks, and search matches;
- canonical pages and blocks with reading order and source metadata;
- detailed text pages, blocks, lines, spans, optional characters, quads,
  confidence, and provenance;
- structure tree, MCID mapping, and ParentTree recovery diagnostics;
- deterministic tables and cells;
- CJK raw text, tokens, offsets, and dictionary pack reports;
- advanced RAG chunks and source citations;
- layout and table proposal backend status and optional merge report;
- privacy/configuration status and exact diagnostics.

## Surface Matrix

| Surface | Entry points | Representation |
|---|---|---|
| Rust | `semantic_binding_report`, `semantic_search_report`, `advanced_chunks` | typed structs plus Serde JSON |
| CLI | `semantic-export`, `chunk --advanced` | focused or full JSON |
| Python | `semantic_bundle`, `advanced_chunks`, `semantic_search`, `table_proposal_status` | Python dictionaries |
| C ABI | `wellfriendpdf_document_*_json` Prompt 15 functions | caller-owned UTF-8 JSON freed with `wellfriendpdf_string_free` |
| WASM | `semanticBundleJson`, `advancedChunksJson`, `semanticSearchJson`, `tableProposalStatusJson` | browser-safe strings from bytes |
| .NET | `SemanticBundleJson`, `AdvancedChunksJson`, `SemanticSearchJson` | idiomatic string wrappers |
| Java | `semanticBundleJson`, `advancedChunksJson`, `semanticSearchJson` | idiomatic string wrappers |

WASM assumes caller-supplied bytes. It has no filesystem-dependent dictionary
pack loader or native ML runtime. No WASM method uploads data.

## Compatibility

The shared report envelope remains version `1`. Prompt 15 adds endpoints and
the feature-report section
`prompt15_semantic_binding_rag_benchmark_closeout`; it does not remove or rename
older report fields. Deep ownership stays at the JSON boundary for C, .NET, and
Java.

The parity artifact is
`target/prompt15-semantic-closeout/semantic-binding-parity-prompt15.json`.
