# Prompt 20B release verdict

Prompt 20B closes the remaining Prompt 20 ownership and range-selection gaps
with bounded implementation:

- logical multi-run range editing across contiguous provenance-aligned
  `Tj`/`TJ`/quote/double-quote string operands;
- recursive selected-instance Form clone-one through parent resource chains;
- selected-owner annotation appearance clone-one for `/N`, `/R`, `/D`, state
  dictionaries, widgets, and nested appearance Form paths;
- undo/redo, branch redo clearing, cache invalidation, semantic/search/RAG
  invalidation, deterministic serialization, and Prompt 18B signature preflight.

No claim is made for cryptographic signature validity, arbitrary Type3 editing,
pattern/shading program editing, partial-token true editing, cross-page ranges,
or ambiguous visual selections.

Prompt 21 may begin only after the final full validation gate and clean commit
for Prompt 20B are present.
