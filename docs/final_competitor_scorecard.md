# Final competitor scorecard

Prompt 30 compares Wellfriend PDF SDK with independently installed tools only where
they are available on the VPS. qpdf is structural evidence; veraPDF is PDF/A
evidence; Poppler/MuPDF/PDFBox/pyHanko are used only for the dimensions they actually
support. Their absence is shown in the tool matrix, never credited as parity.

The scorecard covers bounded public-corpus parser behavior, prior malformed-corpus
and fuzz evidence, released binding breadth, performance observations, and exact
limits. It is not a claim that one engine universally wins on every PDF or workload.
