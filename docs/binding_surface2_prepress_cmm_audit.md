# Prepress CMM Prepress CMM Audit

Prepress CMM adds a first-class prepress color layer on top of the Native CMM Backend
native CMM work. The default build remains portable and uses the existing
fallback preview path. The `native-cmm-lcms2` feature remains the only path that
may use LittleCMS.

Starting checkpoint:

- Expected HEAD: `077e33d`
- Expected commit: `077e33d Close roadmap closure 11B native littlecms cmm backend`
- Expected starting worktree: clean

Prepress CMM artifacts are generated by:

```powershell
python scripts\prepress_cmm_prepress_cmm_audit.py --run-smoke
```

The artifact root is `target/prepress_cmm-prepress-cmm`.

Implemented public surface:

- `ColorReport.prepress_cmm_prepress_cmm_device_link_separation_plates`
- `feature-report.report.prepress_cmm_prepress_cmm_device_link_separation_plates`
- ICC profile class, hash, channel, PCS, native, and fallback diagnostics
- sparse separation framebuffer report data
- spot and DeviceN plate summaries and preview hashes
- rendering intent and BPC cache-key posture

Boundaries:

- RGB page output remains visual preview, not press proof.
- Prepress CMM preserves plate identity and tint data; Prepress Proofing owns full
  overprint compositing.
- PDF/X certification-grade validation is not claimed.
