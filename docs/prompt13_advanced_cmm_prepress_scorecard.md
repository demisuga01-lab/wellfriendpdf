# Prompt 13 Advanced CMM Prepress Scorecard

Prompt 13 closes the advanced CMM/prepress block as a credible bounded
simulation path, not a certified RIP replacement.

Covered:

- native LittleCMS backend posture.
- fallback/qcms/default and WASM preview-only posture.
- ICCBased Gray/RGB/CMYK, device-link ICC, multicolor ICC inventory/output
  limits, output intents, BPC, and rendering intents.
- DeviceCMYK, Separation, DeviceN, true separation framebuffer, spot plates,
  process plates, overprint, color-managed shadings, and color-managed patterns.
- tile/band/progressive/cache equivalence, memory caps, scheduler caps, and
  public report parity across bindings.

Final verdict: Prompt 13 is a bounded prepress simulation close-out. PDF/X
certification and legal standards validation remain owned by the later
standards/validation phase.
