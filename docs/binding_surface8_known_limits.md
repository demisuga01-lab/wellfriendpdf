# secure mutation known limits

- secure mutation closeout closes packed one-bit stencil, common 1/2/4/8-bit Indexed, ICCBased `/N` 1/3/4, bounded TIFF/PNG inline predictors, one-bit inline ImageMask, and executable inline promotion. Unsupported codecs, malformed rows, non-device Indexed bases, and higher-channel ICC profiles remain exact fail-closed cases.
- Supported explicit masks and soft masks are cloned and partially rewritten; unsafe mask codecs or dimension/layout ambiguity remove the affected invocation or fail under strict policy.
- secure mutation closeout closes owner-specific mutation for catalog, page, annotation, structure, Form, and supported XObject owners. RichMedia, XFA, FDF/XFDF, external, and active owner families remain inventory-only or security-policy denials.
- Portfolio UI rendering is not supported.
- DocMDP/FieldMDP analysis is structural. Cryptographic validity, trust, certification acceptance, and viewer status remain separate.
- Executable incremental proof covers metadata, unlocked form values, allowed annotation add/update, and allowed page rotation/CropBox changes. Secure removal operations require full rewrite.
- Caps: 100,000,000 image/mask pixels, recursion 32, 256 MiB inline bytes, 100,000 inline images, 10,000 associated files, 512 MiB per associated file, 2 GiB total associated bytes, 4,096 signatures/policy references.
