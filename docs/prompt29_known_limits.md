# Prompt 29 known limits

Prompt 29 does not claim complete coverage of all PDFs in the wild, full differential equivalence with every external parser, or final release readiness.

Known limits are explicit:

- public malformed corpora are used only when licensing/provenance is acceptable;
- large copyrighted or private files are not committed;
- external tools are counted only when available on the VPS and actually run;
- permissive-tool acceptance of malformed files is not automatically treated as a Wellfriend bug;
- coverage and sanitizer reports are release-hardening evidence, not exhaustive proof;
- low-risk manual-review differentials can remain only when high-severity Wellfriend regressions are zero.

The Prompt 30 boundary owns final stress/performance, final security package/SBOM, API freeze, release checklist, and final go/no-go scoring.
