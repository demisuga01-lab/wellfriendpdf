# Static XFA extraction

Static XFA means a parseable template whose classification does not require flowed/repeated/reflow layout. Wellfriend extracts text, numeric, date/time, choice, check-button, exclusion-group, image/signature/barcode type inventory, captions, assist text, defaults, dataset values, choices, required state, geometry, rotation, presence, font hints, borders/fills, hierarchy, SOM paths, and packet/object provenance.

Supported information is linked into the forms report, token search terms, provenance-aware RAG chunks, accessibility-label counts, the security report, and redaction visibility posture. Embedded image value decoding, complex rich text, proprietary widgets, barcode generation, and signature semantics are reported exact limits; no external image is loaded.

Extraction is read-only and scripts remain inert.
